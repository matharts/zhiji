## 页面结构

1. 首屏以产品定位与下载操作为左侧内容，右侧呈现知几三盘和星空；其后提供五个产品章节入口。
2. 宽幅连续工作区：同一甲子年固定参考盘串起参数确认、飞化观察、标注与留存；按步骤切换侧栏，命盘与飞化选择保持。在线体验直接定位窗口，标注与保存深链接定位相应步骤。
3. 向心与离心对照：左侧宫位与方向图解，右侧对应星曜和筛选状态；支持分别显示、全部显示及全部隐藏。
4. 日期取数与校时：公历、农历、干支反推分别说明输入、处理与确认步骤；桌面为纵向入口列表，手机为横排按钮。
5. 桌面工作习惯：外观预览与紧凑的双平台快捷键表，不再重复展示草稿、导出或飞化。
6. 资源与任务链接；不虚构客户评价、用户规模或第三方背书。
7. 下载前的折叠问答，包含实际支持范围、草稿内容、计算口径与 MIT 许可证入口。
8. 居中下载区与真实版本状态。

功能页继续保留八个主题与原有锚点，关键机制用流程图、参考宫位或标注图承接，辅助主题紧凑排列。

## 约束

- 用户要求保留黑白紫、宇宙星空与天地人三盘，并在本轮要求重新设计首屏和三盘动画。三盘从平面展开为上下三层，交错转动与飞化穿行后收拢，再进入下一次循环；星空实现保持。
- 三盘画布按独立场景的实际尺寸渲染，不通过 CSS 放大画布。减少动态效果或 WebGPU 不可用时显示静态盘面。
- 四化依次点亮，当前光点带柔光和短尾迹；完成的轨迹降低亮度。两条低亮度轨道和两颗缓慢移动的光点提供空间参照，收拢时一同淡出。
- 产品文字、演示数据和链接属于知几；不把 Raycast 或 Framer 的产品能力写成知几能力。
- 固定示例不运行排盘；日期模式、导出倍率、外观等控制仅展示效果。
- 取数流程按当前领域规则表达：公历可选填出生地，不选时固定 UTC+8；农历使用生日与十二时辰；干支反推固定北京时间，不应用出生地或真太阳时修正。
- 单屏方案作为首页 `/`，`/one-screen/` 继续显示同一版式。完整版和参考盘迁至 `/experience/`，原首页章节链接继续跳转到对应位置。展厅、长页和门户三套旧探索稿已下线。

## 本轮细化

- 重新实看 Framer 与 Raycast 的首页、产品演示与功能章节，按主次区分标题与正文，统一章节间距。
- 导航采用沉浸式透明页眉，顶部不设底色或分隔线，星空连续穿过导航区域。左侧为 24px「知几」字标，不使用白底 App 图标；中间入口 15px、间距 36px，窄桌面收为 14px、28px；右侧下载为文字及向下箭头。滚动后以 200ms 淡入顶部向下消失的深色遮罩，无独立底板、外框或背景模糊，不改变布局。桌面内容高 72px、上下各 12px，手机内容高 64px、上下各 8px。当前页以文字下方短线提示，悬停下载箭头下移 2px。手机保持品牌、下载、菜单的操作顺序，菜单以 22px 大字号展开，整页背景压暗，短屏内独立滚动；支持点击遮罩、Escape 与焦点返回、离开焦点和切回桌面时收起。桌面与手机以 701px 为统一分界。

## 混沌开场

- 整段约 24.4 秒循环：旋流混沌 → 两股阴阳云气 → 直接化为一张平面命盘 → 三盘与飞化 → 盘面消隐回归混沌。前奏 9.8 秒、飞化段 12.2 秒、回归 2.4 秒；首屏内容和下载入口始终可用。
- 混沌与阴阳使用同一个 WebGPU 程序雾场，保留湍流、透光和软边，不生成实体太极圆盘、倒角、阴阳眼几何或金属外圈。粒子沿螺旋路径汇聚，再连续迁移至十二宫边缘；雾与粒子共用转动坐标。
- 阴阳阶段不显示完整圆形描边，命盘开始显现后才出现圆方形变轮廓。前奏不展开三盘，云气在盘面显现前持续存在，避免交接空场。
- 主时间轴统一循环前奏、飞化和回归，雾场与粒子在循环接缝共用连续时间；保留暂停、离屏暂停和可见性控制，重播按钮重新从混沌开始。减少动态效果或 WebGPU 不可用时继续显示静态命盘。
- 保留现有画布分辨率策略；不通过 CSS 放大画布或给命盘加模糊滤镜。开场结束后隐藏并停止更新开场粒子，卸载时统一释放几何、材质与纹理。
- 前一轮已检查 320px / 390px 页面无横向溢出。本轮 13 项测试、49 文件 Astro 检查和 7 页构建通过；浏览器实看单盘交接、飞化后回归混沌并自动开始下一轮，无控制台警告或错误。未测量 GPU 帧率，视觉效果待用户审阅。

## 三盘运动节奏

- 分盘由约 4 秒改为 1.55 秒完成，三层启动间隔缩至 60ms；上下面板在展开早期即连续显现，避免等待到后半程才出现。
- 上下盘沿相反方向转动，展开段角行程约 198°，中盘以较小幅度反转。叠加俯仰、偏航和前后错位，维持天地人三层从上到下的可辨关系。
- 合盘顺接最近的整周姿态，避免把大角度旋转整段倒放；收拢约 2.15 秒，随后短暂停留平面。飞化仍依次出现，共用实际盘面矩阵更新落点。
- 不增加粒子、轨迹数量或模糊效果。浏览器已检查桌面与 390px 旋转画面、合盘及下一轮自动回归混沌；未做 GPU 帧率实测。
