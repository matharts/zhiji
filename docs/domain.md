# 领域规则

## 产品范围与术语

知几支持手动模拟排盘与日期取数，也可调整显示、标注、输出图片及保存草稿。手动排盘以 `ziwei-simulator` 的固定版本作为参考。[模拟器基准说明](../tests/fixtures/simulator/README.md)

| 术语 | 在本项目中的含义 |
| --- | --- |
| 排盘输入 `Input` | 性别、干支、紫微位置、月份、时辰、命宫、大限、流年及位星显示；可保留未选择状态 |
| 命盘 `Chart` | 根据当前输入计算的十二宫和星曜结果 |
| 会话 `Session` | 当前输入、结果、显示配置、配色与飞宫的权威状态 |
| 生年四化 | 依生年天干得到的禄、权、科、忌；代码中的部分 `birth` 命名指这一概念 |
| 飞宫 | 用户选中的宫位及该宫干对应的四化 |
| 标注 | 叠加在盘面的线条、图形和文字，可独立编辑和撤销 |
| 批注 | 草稿内带主题、判断、创建位置及一组独立标注的记录 |
| 草稿 | 可重新编辑的 `.ziwei` 文件，区别于已经栅格化的 PNG 图片 |

## 日期取数规则

公历、农历与干支反推均在确认后一次性回填排盘参数。月份与时辰仍可手动调整。反推须先查询并选择候选，取消主弹窗保留原排盘。

### 公历出生地

公历取数可选填或清除出生地。国内按省、市、区县层级选择，选到市即可确认。直辖市和省直辖地区保留实际层级。海外按洲、国家或地区、城市选择，也可搜索地点。确认出生地后更新弹窗的已选地区，取消时保留原值。

选了出生地时，应用使用地点的代表点经度和离线 IANA 时区规则解析钟表时间。地点涉及多个时区或时钟回拨产生重复时刻时，由用户选择。时钟跳过而不存在的时刻无法提交。未选出生地时，应用按固定北京时间 UTC+8 取数。

### 紫微取数

| 规则 | 已确认行为 |
| --- | --- |
| 紫微生年换年 | 公历和农历均按正月初一换年，不提供立春换年选项 |
| 闰月取月 | 初一至十五按本月，十六日起按下月 |
| 闰月取日 | 保留原日数，不减十五。例如闰四月十六的取数月份为五月，取数日数仍为十六 |
| 紫微晚子时 | 23:00–23:59 支持按当天或次日的农历生日取数，默认当天；可在设置中切换 |
| 公历时间 | 提供有效经度时使用真太阳时，经度为 0° 也属于已提供；未提供经度时按输入的钟表时间取数。保留原始钟表时间 |
| 农历时辰 | 保留十二时辰，不区分早晚子时；直接使用所选农历生日和时辰，不补出具体钟表分钟，晚子时设置不对该输入额外推日 |

编辑器内保留原始输入、最近一次解析的时刻及实际农历日期，取数月份、取数日数作为派生参数；这些临时记录不写入草稿，也不作为手动修改后的命盘来源证明。紫微取数规则与干支反推所用的四柱年、月、日柱分界分别定义。

紫占沿用公历取数的农历换算和安星规则，保留当前性别，两种方式均不做真太阳时修正。随机起盘从 1901–2100 年的有效公历日期和十二时辰中等概率抽取，子时取当天 0 点。此刻时间盘使用点击时设备的本地日期和时间，并遵循当前晚子时设置。

### 四柱反推

四柱反推固定使用北京时间 UTC+8。年柱和月柱在立春及各节的交接时刻切换，日柱和时柱按钟表时间判断。日柱可选 0 点或 23 点换日，默认 0 点。晚子时的时干按次日日干计算。紫微晚子时生日和四柱换日分别设置，重启后沿用。

选择甲子年份组后，只查询其中落在 1801–2199 年的部分，并显示实际查询范围。年份组完全超出范围时提示无法查询。

### 计算范围与依据

公历真太阳时使用 1800–2200 年模型。时区数据库的历史记录和未来预测均有覆盖限制。计算有效域、依赖版本及独立对照结果见[历法包说明](../crates/zhiji_calendar/README.md)与[历法验证](research/tyme4rs-calendar-validation.md)。

依赖选择及抽样过程见[历法库评估](research/date-library-candidates.md)。

## 手动输入与显示

- 初始性别为男，其他排盘参数可未选；不完整输入也是有效工作状态。
- 地支选择受已选天干的阴阳配对约束。已有地支时更改天干，地支切到新天干对应的首个可选值。
- 月份和时辰均有值时推算命宫。手动选择命宫须已选天干与紫微，并清空月份和时辰。
- 有命宫才可选大限，有大限才可选流年；命宫变化时大限跟随命宫，流年可单独重置。
- 选中宫位显示飞化，再次点击取消，点击另一宫切换；输入变化后依当前宫干刷新。
- “重置排盘数据”清空输入和飞宫，保留显示选项、配色与标注；颜色另行重置。

显示状态与计算输入分开管理。位星开关属于现有计算输入，其余显示开关不应无故重算。显示与输入变化不得重置无关的编辑或后台任务。

自化向性的向心、离心分别点选开关，可同时显示或全部隐藏；“全部”在全选时清空，否则全选，与四化类别开关共同过滤显示。向性切换保持命盘计算结果和箭头几何，仅控制相应标记是否绘制。

## 标注与图片

标注支持选择、移动、调整、文字编辑、层次调整以及撤销和重做。隐藏标注只影响显示，不删除数据。

标注调色板提供亮蓝、青绿、草绿、紫、琥珀和炭灰，也可以自定义颜色。标注的颜色随当前版本草稿保存。

屏幕与图片输出共享宫格、箭头和标注绘制。导出和复制只含发起时可见的标注，不含选框、光标或手势预览。草稿保存全部标注和可见性；撤销历史只属于当前会话。

批注的创建位置使用命盘基准坐标保存。选中批注时只显示并编辑该组手动添加的标注，排盘参数、流年和飞宫保持当前选择。未选批注或收起索引时使用通用标注。各组分别保留会话内的撤销、重做和可见性。图片包含当前组的可见标注，批注正文仅在草稿工作区显示。

## 草稿格式

当前读写版本 4，不支持版本 1、2、3。未知字段（包括嵌套对象）、其他版本以及无效的排盘、飞宫、标注或批注数据在替换会话前拒绝。草稿不包含日期字段。

显示配置在仅向心或仅离心时保存 `self_direction`（`inward`、`outward`），全部隐藏时保存 `none`；全部显示时省略该字段，已有版本 4 草稿仍可原样往返。读取缺省字段或显式的 `all` 均表示全部显示。日期取数中的临时选择和出生地不写入草稿。

草稿中的生年地支若已选择，须有天干且阴阳配对一致；其他未选的排盘参数仍可保留为空。

保存时同样检查标注的读取限制；超限或无效时报告失败，保留当前内容和已有目标文件。草稿文件大小也受到限制。

有批注时按创建顺序写入 `comments`。每份草稿最多 256 条，每条包含基准盘面坐标 `position`、最多 80 字的单行主题 `title` 和最多 4000 字的正文 `body`。批注中的 `marks` 在有标注时写入，`visible` 在隐藏标注时写入。缺省时分别表示没有标注和标注可见。草稿根层的 `marks`、`visible` 仍表示通用标注。各组共用整份草稿的标注数量和笔画点数上限。缺省或空的 `comments` 表示没有批注。含新增字段的文件需用支持这些字段的版本打开。主题选择和索引展开状态仅用于当前窗口。

保存的飞宫值恢复后先保持原值；实际计算输入变化后再刷新。
