# 知几使用帮助

知几用于手动排盘、调整命盘显示、添加标注，以及保存草稿或导出图片。

## 开始排盘

1. 在右侧面板选择排盘参数。选择会立即反映到命盘；尚未选择的参数可以留空。
2. 也可以点击标题栏的**日期取数**按钮，选择公历、农历或干支反推，填写所需信息并确认。干支反推需要先选择候选时间；遇到重复的当地时间时，也需要选择对应时间。
3. 日期取数确认后会回填排盘参数。你仍可在右侧面板手动调整。

标题栏可切换单双列布局、收起或展开右侧面板、切换日间和夜晚模式，以及打开设置。右侧面板中的显示设置可控制盘面内容；需要重新选择排盘参数时，可使用面板中的“重置排盘数据”并确认。

## 保存与打开草稿

草稿使用 `.ziwei` 文件，保存当前命盘参数、显示状态和标注。**日期取数时输入的原始日期、出生地及换算过程不保存在草稿中**；如需留存这些资料，请另行记录。

- 在命盘下方标注工具栏的“更多标注操作”中选择**保存草稿**。首次保存需要选择文件位置；已有路径时会直接保存。
- 选择**另存为**可保存到另一位置；选择**打开草稿**可打开已有文件，**打开最近**可查看最近成功打开或保存的草稿。macOS 用户也可从系统“文件”菜单使用这些操作。
- 标题栏显示当前文件名；文件名旁的 `•` 表示有未保存的更改。
- 打开其他草稿或退出应用时，如果当前内容尚未保存，可选择“保存”“不保存”或“取消”。
- 如果原文件已被其他程序修改或删除，直接保存时会询问如何处理；确认前不会直接覆盖。

当前应用只支持当前草稿格式。如果文件无法读取，应用会提示错误并保留当前命盘。

## 标注与图片

命盘下方的工具栏提供选择、绘制和文字等标注工具，以及撤销、重做操作。在工具栏的“更多标注操作”中可显示或隐藏已有标注，也可选择**复制图片**。

点击工具栏上的**导出图片**，选择保存位置，即可保存 PNG 图片。图片倍率可在设置中调整；复制图片使用固定的 2× 倍率。图片用于查看和分享；需要以后继续编辑时，请另存一份 `.ziwei` 草稿。

## 快捷键

以下快捷键在 macOS 使用 Command（⌘），在 Windows 和 Linux 使用 Ctrl。文件确认或日期取数等弹窗打开时，快捷键可能先作用于当前弹窗。

| 操作 | macOS | Windows / Linux |
| --- | --- | --- |
| 打开草稿 | ⌘ O | Ctrl+O |
| 保存草稿 | ⌘ S | Ctrl+S |
| 另存为 | ⇧ ⌘ S | Ctrl+Shift+S |
| 导出图片 | ⇧ ⌘ E | Ctrl+Shift+E |
| 打开设置 | ⌘ , | Ctrl+, |
| 退出应用 | ⌘ Q | Ctrl+Q |
| 撤销标注 | ⌘ Z | Ctrl+Z |
| 重做标注 | ⇧ ⌘ Z | Ctrl+Shift+Z 或 Ctrl+Y |
| 取消当前操作或关闭弹层 | Esc | Esc |

撤销和重做在文字或颜色编辑时遵循当前编辑状态；标注操作需要有可撤销或可重做的记录。

## 设置与退出

在标题栏打开**设置**，可调整外观、界面简繁体、命盘简繁体、动态效果、界面字号、配色、图片倍率和窗口布局等。界面与命盘文案可分别选择并混用；字形区域风格随界面用字。设置中的“关于”可查看应用版本、配置目录和许可证；版本号旁的复制图标可复制应用名称、版本、操作系统和运行架构。

**检查更新**在应用内查找新版，不打开浏览器。**自动更新**默认开启，后台定期检查并下载；关闭后仍可手动检查。下载过程中可取消，完成后选择**重启并更新**或**稍后**。重启前会提示保存未保存草稿，取消或保存失败时保留当前工作。稍后处理时可在本次会话的设置页继续安装，普通退出不自动安装。macOS 完整应用包、Windows 安装版和 Linux AppImage 使用相同流程；Linux DEB 由系统包管理渠道更新。

点击**使用帮助**可在应用内离线查看本指南，并切换到**快捷键**页查看当前平台的按键。按 Esc 或点击关闭按钮返回；macOS 的“帮助 → 知几帮助”打开同一面板。

点击**反馈问题**会在浏览器中打开新建问题页，需要网络连接。页面预填相同的环境信息；填写问题描述、复现步骤和预期结果后，由你提交。

如果遇到草稿、导出或设置保存问题，可在“关于”的**诊断日志**一行点击**打开目录**查看本地日志，或点击旁边的复制图标复制目录路径。默认日志保留最近两份，每份最多 512 KiB，记录失败阶段与错误类别；目录无法打开时，可用复制的路径手动查找。日志不会自动发送，反馈时可按需提供。

macOS 上关闭窗口会保留当前会话，可通过 Dock 图标重新打开；要结束应用，请使用“退出知几”或 ⌘ Q。Windows 和 Linux 上关闭窗口会退出应用。**关闭窗口不会自动保存草稿**，请先保存需要保留的内容。
