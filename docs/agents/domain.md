# 领域文档读取约定

采用单一上下文：术语表为根目录 `GLOSSARY.md`，决策记录位于 `docs/adr/`。只在术语得到确认或确有决策需要记录时创建，不预建空文件。

探索代码前，读取已有术语表及与当前工作相关的决策记录；不存在时继续工作。对领域概念使用已确认名称，发现冲突时指出，不默默改写既有决策。

本文件只规定文档读取方式，不重复业务规则。排盘与草稿规则由 [领域规则](../domain.md) 负责；模块职责由 [架构](../architecture.md) 负责；交互行为由 [界面规范](../interface.md) 负责。术语表只记录术语，不承载实现细节或需求规格。

仅对难以逆转、缺少背景会令人困惑、且确实经过取舍的决定记录 ADR。规范变化同步到现有负责文档，ADR 保留决策理由，不另建一套并行规范。
