# 可复现构建验收

Status: ready-for-agent
Progress: resolved
Blocked by: none

## 目标

审查当前待交付文件，冻结包含已暂存、未暂存及未跟踪源码的候选快照，在独立目录和空项目构建目录中验证检查、构建与 macOS 打包。保留文件清单、工具版本、日志与产物校验值。

## 边界

不提交、不暂存、不创建分支，不修改现有业务实现或关闭用户应用。共享已下载的工具链及依赖缓存，禁用编译包装器；不复用原项目 target 或网站 node_modules。快照验证不等同于干净提交验收、位级确定性构建或三平台发布验收。

## 验证

1. 核对 Git 文件清单、遗漏文件、路径依赖和高置信度凭据模式。
2. 在隔离快照运行资源、格式、Clippy、Rust 及 GPU 检查。
3. 从空 release 目录构建并打包 macOS 应用，验证签名和产物摘要。
4. 网站从锁文件安装、测试、类型检查并构建。
5. 比对快照与原工作区的后续漂移，记录实际结果与提交准备建议。
