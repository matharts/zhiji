# 应用与功能模块职责收拢

Status: ready-for-agent
Progress: resolved
Blocked by: none

## 目标

保持现有单体桌面结构、领域计算、文件格式和界面表现，落实已审阅的四项结构优化：

1. 应用根视图、标题栏和跨功能菜单归 `app/view`，工作区视图通过宿主接口复用，不依赖 `AppState`。
2. 更新状态机和诊断能力独立于 `app`；应用层只绑定窗口、操作和弹层，设置页通过只读状态和动作使用能力。
3. 工作区持久偏好、布局状态及临时交互分别建模，不引入重复可变状态。
4. 当前文档的路径、保存基线和操作状态直接归应用的文档入口，不再混入图片任务组。

## 实施边界

保留 `Session`、快照隔离、既有保存/退出语义和现有三项内部 crate。目录调整必须同时消除旧引用；不新增通用服务容器、事件总线或应用依赖。工作区交互回归仍可通过测试根状态组合应用视图，生产工作区不依赖应用根状态。

## 验证

检查反向依赖与残留引用，运行统一 Rust、GPU、release 打包/签名及 macOS 菜单、文档和辅助功能检查。补充独立宿主的日期编辑绑定和状态作用域回归。记录实际结果及未覆盖平台。

## Result

四项调整已完成。543 项 Rust、21 项 GPU、release 打包/签名、Windows 目标检查及 macOS 菜单、文档、辅助功能检查通过。原生自动化曾出现激活和窗口读取波动，分别复测通过；Windows/Linux 实体桌面未在本轮重新验收。详见[优化记录](result.md)。
