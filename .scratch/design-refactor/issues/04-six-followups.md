# 修复审查剩余六项

Status: ready-for-agent
Progress: resolved
Blocked by: 01, 02

## 工作范围

1. 设置保存失败时阻止普通关闭静默结束，提供重试、继续使用及明确放弃设置退出。
2. 有界读取设置，区分不存在、读取失败和格式损坏；故障时保护原文件，明确提供恢复入口。
3. 设置视图使用只读投影和类型化修改，按职责拆分宿主；集中默认值和持久化映射。
4. 历史按需后台读取，等待期间不推进栈，后续编辑作废尚未应用的历史操作。
5. 原生测试使用隔离应用身份；补充性能测量与能执行的平台检查，保留实机缺口。
6. 同步日期计算状态及相关职责、恢复和验证规范。

## 验收

定向验证保存失败退出、损坏及超大设置保护、字段修改与恢复、慢历史读取及新编辑交错。运行统一 Rust、GPU、macOS 原生检查及 release 性能测量。Windows/Linux 不能以交叉编译替代实机结论。

## Result

六项实现已完成：设置保存失败退出确认、故障配置保护与备份恢复、只读偏好投影及类型化修改、历史按需可取消读取、隔离原生验收及性能测量、文档状态同步。

541 项 Rust、21 项 GPU、release 打包及签名通过；最终 macOS 菜单/设置恢复、文档流程与辅助功能检查连续两轮通过。原生脚本另修正 LaunchServices 完成回调早于实际激活的问题，以及无障碍节点回环导致递归溢出的问题，保留原有断言。Windows 目标构建通过，Wine 执行 40 项定向测试通过；Linux 最终 ELF 在 Ubuntu/Xvfb/软件 Vulkan 环境中通过 AT-SPI。

100 万点历史在本机热缓存 release 测量中，同步读盘 p50 为 16.98 ms，异步 UI 提交 p50 为 22.1 µs，完整异步读取 p50 为 17.19 ms；改进在 UI 阻塞时间，不能据此宣称总读取更快。详细条件、命令、日志与其余边界见[审查报告](../review.md)。

Windows/Linux 实体桌面、Wayland、中文输入法和长期压力不在已验证结论中，后续实机验收保留在任务 03。未提交 Git，未改依赖、领域算法、视觉基准或比较容差。
