# 应用任务与输入状态重构

Status: ready-for-agent
Progress: resolved
Blocked by: none

## 目标

以当前工作树为审查基准，改善桌面应用的任务生命周期、状态有效性与界面响应。保留命盘规则、文件格式、资源和视觉基准，不引入依赖。

## 本轮实现

1. 设置写入移出 UI 线程；串行提交，一项执行中、一份最新待写快照。失败不通过逐帧配色比较自动重试；后续操作或关闭可重试。退出等待设置写入，更新安装继续受设置失败保护。
2. 四柱反推支持协作取消；每个编辑器最多一个执行任务和一个最新待执行请求。输入变更及销毁取消计算，旧任务完成后才运行新请求，旧结果不能回写。
3. 日期候选、时区确认和重复时刻确认使用互斥步骤；按钮返回与 Escape 共享步骤返回行为。

## 审查依据

- `src/app/state.rs` 的 `persist_preferences` 同步执行 JSON 编码和文件替换；配色保存失败不推进基线，`poll` 会重复写入。
- `src/workspace/input/mod.rs` 的失效操作只丢弃接收端；线程仍在历法包的逐秒循环中计算。
- 日期步骤由三个独立 `Option` 以及独立候选选中值表示；视图和 Escape 使用不同的优先级与清理逻辑。
- `Session` 已拥有生效排盘状态，图片和草稿任务已有快照隔离，保留这些职责。
- 偏好读取/修改接口及工作区字段仍有较多重复接线；完整存储模型、历史同步读取和其他后台任务须后续按具体行为独立审查。

## 验收

确定性交错测试覆盖合并、取消、过时结果、异常、失败重试和退出；运行统一 Rust 检查与 GPU 回归。不更改基准或容差，不把离屏结果当作原生交互验收。
