# Windows 命盘与标题栏显示修复

用户报告 Windows 安装后，窗口内大限宫名偏上，复制图片的位置正常；右上角窗口控制按钮不可见。

- 窗口控制按钮采用应用当前主题的导航文字颜色，不依赖系统深浅色。
- Windows 大限宫名与盘内其他同字号中文共用低 DPI 基线补偿，保持 2× 复制图片位置。
- macOS/Linux 保持既有盘面位置；Linux 继续保留系统原生窗框，未复现前不假定与 Windows 使用同一修复。
- 保持宫格、字号、配色、动画与原生窗口命中逻辑。
- 验证常见桌面缩放、静态与动画路径、Rust 检查及 GPU 回归。macOS 检查不能替代 Windows 原生验收。
