# 应用内自动更新

用户要求“检查更新”使用桌面应用的检查、下载、安装流程，同时接入自动更新，不跳转 GitHub。

三端采用统一 Rust 更新状态机、签名协议和界面，安装格式与 cargo-packager-updater 配套：macOS 应用包、Windows NSIS、Linux AppImage。用户进一步明确三端必须实现，并要求一致方案，因此不保留 Sparkle 分支。默认自动检查并下载，重启由用户确认；设置可关闭自动检查。更新退出复用草稿保存和后台任务收尾，取消或保存失败保留当前会话。运行时不接受环境变量覆盖更新源或公钥。

更新源按平台及架构分别生成，先验证元数据签名，再验证下载包签名。私钥留在仓库外的受限文件或发布环境，不进入仓库。只准备发布产物，不擅自发布或配置远程 secrets。Linux 保留 DEB 系统包渠道，支持应用内自更新的主发行包为 AppImage；不覆盖由系统包管理器维护的文件。

验收：Rust 行为回归、签名和篡改拒绝、下载取消及超限、保存保护、安装回滚、三端构建、打包及界面检查；原生平台验收与交叉编译分别记录，不把本机验证当成三端实机验收。
