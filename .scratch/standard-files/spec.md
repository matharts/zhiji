# 标准文件体验

Status: ready-for-agent
Progress: resolved

## 目标与范围

在现有单工作区和草稿文件格式上补齐当前文件名、未保存标记、直接保存、另存为、最近文件，以及打开其他草稿和退出应用时的未保存保护。不增加排盘能力，不改命盘绘制，不引入自动保存、文件关联或多窗口。

## 已确认行为

1. 排盘参数、飞宫、标注、标注显隐、盘面显示设置和配色发生变化，均算未保存修改；窗口布局及其他全局偏好不算。
2. 保存只确认发起保存时捕获的内容。保存期间的新修改仍未保存，不能因后台任务成功而被误标为已保存。
3. 打开或保存成功后记住文件路径。保存已有文档直接写入当前路径；首次保存和另存为使用系统路径选择。另存为成功后切换当前路径，取消或失败保留旧路径。
4. 直接保存前发现目标被外部修改或删除，停止自动覆盖，提供另存为、明确覆盖、取消。未确认不能破坏外部文件。
5. 打开另一份草稿或退出应用，若存在未保存修改，提供保存、不保存、取消。选择保存后，只有保存成功且没有新修改，才继续原操作；取消或失败保留当前内容。
6. macOS 关闭窗口保留会话；真正退出才检查未保存修改。Windows/Linux 的关闭即退出，需要同等保护。
7. 重置排盘沿用现有确认；只重置参数和飞宫，保留标注、显示和配色，完成后按内容变化标记未保存。
8. 文件名与未保存状态可见，系统菜单和快捷键共用行为。已有保存为 Command/Ctrl+S，另存为为 Command/Ctrl+Shift+S。
9. 最近文件只记录成功打开或保存的路径；读取失败保留当前文档并反馈错误。

## 边界约定

- 初始未修改工作区是干净状态；修改后又完整还原至已保存内容，应回到干净状态。
- 草稿继续使用当前格式，不加入原始日期、出生地或校正元数据。
- 文件写入保留临时文件和明确冲突确认机制。外部检查不能被表述为对其他进程的绝对文件锁。
- 当前仓库包含大量此前及并行改动，本轮不得包含或撤销这些改动。

## 已确认的验收边界

1. 草稿模块对外操作：真实临时文件中的保存、读取、修改冲突、取消与失败；观察结果和文件内容，不绑定内部数据结构。不能证明原生对话框可用。
2. 应用操作与 Runtime：保存期间继续编辑、未保存提示的三种选择、打开/退出继续执行和关闭保留；观察工作区、提示和退出请求。不能证明操作系统事件送达。
3. macOS 打包应用：菜单、快捷键、文件名与状态、系统文件对话框和退出交互。真实 Windows/Linux 交互另记为未验收。

## 已确认的审查基线

使用本轮开始前保存的工作区文件快照审查本轮差异，不以 HEAD 中的大量历史差异作为本轮成果。按现有项目规范和本规格分别审查。建议本轮保留工作区改动、不创建提交，以免把既有改动混入提交。
