# 草稿批注

在盘面右键创建批注。每条保存自定主题、判断、创建位置和独立的图形及文字标注。细线书签在命盘左侧灰色留白居中，当前项填实。左侧留白过窄时，书签改在命盘下方的灰色间隙居中。悬停浮出主题和正文，卡片随文字和窗口尺寸适配。点击书签切换当前组手动绘制的标注，再点一次取消选择。索引与卡片均不占用命盘的布局空间。

切换后沿用底部工具编辑该组标注，撤销和重做归属当前组。从卡片菜单编辑主题或正文，删除整组需确认。收起索引返回通用标注，再展开恢复当前条目。各组都随草稿保存并参与未保存判断。已有 v4 草稿的标注保留在通用组内。

参见 [实现与验证](issues/01-draft-comments.md)。
