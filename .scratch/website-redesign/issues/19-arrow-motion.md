# 官网箭头动画

## Scope

将命盘飞化及向心、离心示意的箭头改为尖端与线身同步前进，消除尖端提前出现在终点的割裂感。已显示的自化方向不因另一方向切换而重复播放。

## Validation

执行官网 test、check、build，并在浏览器检查中途尖端、快速切换、结束还原和减少动态效果。

## Result

- 飞化箭头用同一弧长进度驱动线身与尖端，480ms 匀速绘制；自化方向使用 420ms。完成后移除临时尖端，还原原 SVG 标记。
- 自化只播放刚开启的方向，另一个已显示方向保持不动；键盘操作直接显示结果。
- 切换宫位、停止播放、切后台、离开页面或动态效果偏好变化时清理逐帧任务；减少动态效果时直接显示完整箭头。
- `mise exec -- node tools/verify.ts website` 通过：14 项测试、55 文件 Astro 检查零诊断、静态构建成功。
- 浏览器读取中间帧：飞化线身进度约 50% 时，尖端位于曲线中段而非终点；连续切换宫位只保留一个临时尖端，结束后仅剩原路径。自化只为重新开启的方向生成临时尖端，另一方向不重播；最终均还原为一条原路径。
- 已目视检查最终 SVG 箭头。系统减少动态效果的实际切换与后台中断尚未在浏览器实测；视觉节奏待用户确认。
