# 草稿交互补强

Status: ready-for-agent
Progress: resolved
Blocked by: none

## 目标

在不增加窗口菜单栏、不改变草稿格式和命盘几何的前提下，让草稿的新建、打开、保存与结果反馈更容易找到和理解。

## 范围

- “更多操作”按草稿与标注分组，补“新建草稿”、动态“保存草稿…”文案和分隔线。
- 新建草稿复用未保存保护，清空当前排盘、飞宫和标注，保留配色、显示、排盘规则及窗口布局偏好。
- 草稿保存或打开的结果显示在文件名下方；保存失败提示延长到 8 秒。
- 最近文件按文件名和所在目录展示，长列表在小窗口中滚动。
- 三平台支持新建快捷键；macOS 系统“文件”菜单同步增加入口。

## 非目标

- 不恢复此前已否决的 Windows/Linux 窗口菜单栏。
- 不修改 `.ziwei` v4 格式、领域计算或命盘绘制。

## Result

- “更多操作”已完成草稿/标注分组，新增新建草稿、动态保存文案和分隔线；草稿反馈移至文件名下方，失败提示保留八秒。
- 新建草稿复用未保存决策，保留配色、显示、排盘规则和布局偏好；最近文件改为文件名加目录并支持滚动。
