# 命例库布局原型

仅用于比较设计，不接入桌面应用、不读取真实命例。外观参考现有桌面应用的标题栏、字体、颜色和控件；命盘工作区与“更多操作”入口用于展示页面之间的关系。命例资料为合成数据，12 组盘面按各自的输入参数通过应用的排盘和导出代码生成，重复资料复用对应盘面。

- `combined.html`：整合版，以窗口宽高各 95% 的弹窗展示命例库，可收起分组侧栏，在列表和卡片之间切换，并从专题书架进入命例。
- `index.html`：四种方案对照入口，底部切换；数字键 1–4 或左右键切换。
- `catalog.html`：目录式列表，整页检索、筛选和批量选择。
- `cards.html`：命例卡片网格，以盘面和笔记预览浏览。
- `groups.html`：分类导航与命例目录，通过标签和来源定位。
- `shelves.html`：专题书架，先选择命例集，再进入目录与详情。

四版提供搜索、排序、独立详情、资料编辑、回收站和昼夜切换等演示。保存和修改只保留在当前浏览器页面内，刷新即重置。选择草稿文件仅使用文件名演示导入流程，不解析文件；新增命例没有盘面预览。原型不执行实时排盘，从命例打开盘面后调整参数会停止展示原盘面。

通过仓库根目录的静态服务打开，或直接打开各 HTML 文件。字体引用仓库内资源，预生成盘面位于 `charts/`。
