# 命例库整页与大数据存储

> 历史规格。桌面实现已撤出，当前项目保留 [HTML 交互原型](prototypes/README.md)。下文记录此前探索的范围与结果。

Status: ready-for-agent
Progress: claimed
Blocked by: none

## Scope

- 命例库使用新页面，不作为弹窗。
- 左侧搜索、标签、目录及虚拟列表，右侧盘面阅读或资料编辑。
- SQLite 事务存储快照与元数据，数据库筛选、分页、按需详情。
- `.ziwei` 草稿格式和无关命盘外观保持不变。

## Result

已完成整页重做。目录展示标题、笔记预览、盘面摘要、标签、来源和更新时间；右侧阅读页显示实际盘面缩略图、完整笔记及资料。窄窗口压缩盘面列并限制缩略图高度，夜间主题与 1.25 倍界面字号纳入回归。

存储使用 `casebook.sqlite3`、FTS5 trigram 和 WAL，续页按更新时间与编号游标读取。虚拟行在构建页面时冻结主题色、字号倍率和界面用字，避免布局阶段脱离作用域；目录支持上下键移动选择。

验证：`cargo test casebook` 21 项通过；`mise exec -- node tools/verify.ts rust` 通过（607 项）；离屏截图覆盖 1300×800、900×600、2× 和夜间主题。截图位于 `screenshots/`，不作为固定视觉基准。未执行真实窗口点按和中文输入法验收。
